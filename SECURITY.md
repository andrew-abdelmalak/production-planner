# Security policy

## Supported versions

| Version | Supported |
|---|---|
| Latest (`main` / `0.1.x`) | Yes |
| Older snapshots | No |

Only the latest state on `main` receives fixes.

## Report a vulnerability

Do not report security problems in public issues or pull requests.

Report them privately through [GitHub private vulnerability reporting](https://github.com/andrew-abdelmalak/production-planner/security/advisories/new).

Include:

- The affected commit or release tag
- Steps to reproduce or a proof of concept (such as malformed workbook or JSON inputs causing unintended behavior)
- Expected impact

You will receive a response as soon as the maintainer reviews the private advisory.
